## 三、Redesign 类（不是错，但实装前要知道成本）

- 三列网格（现为 2 列 LazyVGrid）、彩色类型 chip 替代系统文件图标、目标卡悬停「放下 · 移动 2 项」提示——现 `onDrop(isTargeted: nil)` 无拖放高亮状态，要先加 isTargeted 绑定
- D 的全键盘流：↑↓ 选 / Space 多选 / 数字键直达 / N 新建 / ⏎ 确认 / R 改名 / S 瘦身——**全部不存在**，这正是产品定位里"键盘分拣循环缺失"的 gap，是最大的一块新实现
- D 的「S 瘦身」单键触发需要定默认质量档（现为 high/balanced/extreme 三档菜单）
- D 砍掉了 stepper/toast/AI 条，且仅深色——需补浅色适配（artifact 取舍栏已自认）

## 七、评审后 Kyle 反馈（2026-09-18，实装约束）

1. **保留美术资源**：文件/文件夹图标沿用系统真实图标（NSWorkspace/FileIconCache），概念稿的彩色类型 chip 不采纳。定稿皮肤围绕真实图标做。
2. **新增默认目标「回收站」**：已实装（v0.6.1 本地构建）——`MoveEngine.trash` 走 `FileManager.trashItem`，与移动共享 undo 栈（撤销=从回收站拉回原位，撤销 P0 不破）；网格末位固定瓦片，悬停红色 trash.fill，点击/拖放均可，toast「已移入回收站 N 项」，日志记「→ 回收站」。未加入 scoot CLI，按需后补。
3. **文件夹操作**：无需开发——列表本就含目录（SourceWatcher.scan 不过滤），可选中/拖拽/移动/回收站，slim 自动排除目录。
4. **筛选（按添加时间/类型）**：Kyle 选了胶囊方案，已实装——左栏列表顶部一排单选胶囊「全部/今天/图片/文档/压缩包/其他」（ScootCore.FileFilter + FilterChipsRow），切换筛选清空选择防止"隐藏文件被误移"，徽章显示「筛出 N 项」，筛空显示空态，源文件夹为空时不显示胶囊行。已知边界：AI 分拣在无选中时仍处理全部文件（不感知筛选），待用户反馈再决定是否收窄。

## 八、评审小结（不替代方向拍板）

- **B** 离现状最近、实装最省；**D** 对比度唯一全过、与"键盘优先"定位一体，但新实现量最大（整个键盘层 + 浅色）；**A** 生态最统一但整套色板要调；**C** "编号=键位"双关最巧，小字对比度必须修。
- 无论选哪案（或混搭），第一节 6 条编造类逐条拍板后才可开工；全状态稿出来后按本表复核一遍。
